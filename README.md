# AMANTER

Статический сайт AMANTER с админ-панелью (`/admin`) и Vercel Functions для серверной авторизации и статистики.

Для включения статистики и входа администратора добавьте переменные Vercel по инструкции в [ANALYTICS_SETUP.md](ANALYTICS_SETUP.md). Реальные секреты храните только в Vercel Environment Variables, не в репозитории.
